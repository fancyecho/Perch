Perch 0.7.0：时间轴能直接拖着改时间，铺满一整天；重复任务、晚间整理，灵动岛认得更多设备。

## 新功能

- **拖着改时间**：在时间轴上按住任务上下拖，它会浮起来跟着指针沿线移动，放到哪里就是哪个时间；靠近别的任务或「现在」时自动首尾相接，拖到列表边缘会自动滚动。拖胶囊下边缘改时长。都按 5 分钟吸附，可以撤销。
- **点空闲加任务**：点时间轴上的「空闲」时段，那段时间会填进输入框，接着写标题就行。
- **一整天的时间轴**：时间轴从早上画到晚上（默认 7:00–23:00，在「设置 → 任务」里调，有更早或更晚的任务时自动延伸），时间列里轻轻标着上午 / 下午 / 晚上。
- **重复任务**：每天、工作日、每周……做完会自动排到下一次；不想做这次可以直接跳过。
- **晚间整理**：到了设定的时间（默认 21:30），「今天」顶上列出还没做完的，一键勾掉或挪到明天。之前几天剩下的也会这样列出来。

## 改进

- **提醒**：有了时间轴，默认改成时间段结束时提醒；任务开始时的提醒可以在「设置 → 任务」里单独打开。
- **灵动岛认得更多设备**：AirPods 和 Beats 按型号显示（充电盒也对得上），头戴耳机、音箱、显示器、键盘、鼠标、手柄等都有各自的图标。
- **灵动岛横幅更生动**：设备连上时图标轻轻一落，切到音箱时漾出一圈声波；换了另一台设备会换一条新横幅，而不是在原地改名字。
- 去掉了右键菜单里已经没用的「系统状态」。

## 修复

- GitHub 暂时出错时，更新检查会把错误页当成更新包，导致签名校验失败。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.7.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
- Perch 未经公证，更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次。
