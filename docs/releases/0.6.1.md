Perch 0.6.1：新图标，灵动岛清单能滚到底，时间轴更顺手。

## 新的图标

- 换成了 Perch 的任务胶囊：一枚蓝色的勾选按钮，下面露出下一项任务。

## 改进

- **完成的任务自动收起**：时间轴上做完的事留在原位，但收成一行：线上一颗小圆点，划线的标题后面跟着小字的时间。勾选时胶囊会收缩成圆点，取消勾选再展开。
- **左右扫不再扯断时间轴**：扫动时只移动文字，时间和胶囊留在线上。右扫时胶囊随手指填满、过阈值变成对勾；左扫时胶囊淡出，露出「明天」。
- **滚动条**：任务清单和专注页换成一条细细的胶囊滚动条，鼠标移上去时淡淡出现，滚动时更清楚，停下后淡出。
- **设置窗口统一大小**：所有页面一样大，切换标签时窗口不再跳动，内容多的页面可以上下滚动。

## 修复

- 任务显示在「灵动岛里」时，打开的清单无法滚动。
- 任务显示在「刘海下的胶囊」时，如果灵动岛正展开（播放器或状态页）时打开清单，清单底部会被切掉，最后几项看不到。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.6.1.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
- Perch 未经公证，更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次。
