Perch 的第一个版本：一只停在屏幕角落、始终置顶的待办小鸟。

## 亮点

- 玻璃胶囊 → 悬停预览 → 完整面板，三种形态连续形变；拖动后磁吸屏幕边缘
- 自然语言录入：`明天下午3点 写周报 !! #工作`，日期、时间、优先级、标签实时解析（中英文都支持）
- 触控板横扫：向右完成，向左推迟到明天；勾选动效、撤销、专注计时、到点通知
- 全局快捷键可自定义；中文 / English 界面；时区可选并正确处理夏令时
- 内置自动更新：从 GitHub Releases 获取新版本，Ed25519 签名校验通过后才安装

## 安装

1. 下载下方的 `Perch-0.1.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。
2. 应用未经 Apple 公证，首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
   ```
   xattr -dr com.apple.quarantine /Applications/Perch.app
   ```

需要 macOS 26 或更高版本。`Perch-0.1.0.zip.sig` 是更新校验用的签名文件，手动安装时无需下载。
