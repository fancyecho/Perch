Perch 0.4.0：专注、系统状态和 Dayline 的时间并入 Perch。

## 新功能

- **专注**（原 Focus）：按 `⌥⌘F` 或离开电脑一段时间，所有屏幕慢慢模糊，只留一句话和时钟；长按 `⌥⌘F` 约 4 秒或打出解锁语句才解除。
  - 正在专注某项任务时，模糊画面会写着这项任务，解除后问一句「做完了吗」，点一下就勾掉。
  - 模糊期间灵动岛和胶囊让开，只有到点提醒和音量、亮度提示会出现。
  - 任务面板新增「专注」页（`⌘5`）：今日专注、最近 7 天、开始专注，以及所有时段的开关。
  - 今日专注时长把模糊屏幕、专注某项任务、正常进行的时段都算进去，重叠的时间只算一次。
- **时段**：每天固定时间暂停分心的 App 和网站，分温和与严格两种。
  - 温和时段可以按住按钮再用 5 分钟，倒计时显示在刘海两侧，展开刘海可以提前结束。
  - 严格时段进行中不能跳过、修改，也不能退出 Perch；可选「防止被强行退出」。
  - 时段进行中，胶囊外圈多一道正在燃尽的「灯油」环。
  - 时段和待办共用同一个时区（设置 → 通用 / 专注）。
- **系统状态**（原 MacStatus）：
  - 灵动岛展开后双指上下滑、滚动鼠标滚轮或点左边的圆点，在「正在播放」和「系统状态」两页之间切换；往下滑翻到下一页，状态页从下面升上来。
  - 状态页是 CPU、内存、温度、网速读数，点读数在下面显示它最近两分钟的曲线和平均、峰值等数字。
  - 完整的系统状态面板（CPU、内存、GPU、磁盘、网络、电池、进程）从菜单栏读数或 Perch 菜单打开；菜单栏读数可选。
  - CPU 过热、内存吃紧、磁盘快满、进程长时间占满 CPU 时，刘海弹出提醒。
- **胶囊里的时间**（原 Dayline）：默认每分钟最后几秒，任务翻走、时间升上来，看着分钟数字滚过去再换回任务；也可以设成和任务轮流、平常一直显示时间（悬停才看任务），或关闭。样式沿用 Dayline，设置在「设置 → 待办」。
- **输出设备**：播放器进度条右端显示当前的输出设备，点它可以切换到别的扬声器或耳机。
- **灵动岛快捷键**：`⌥C` 显示 / 关闭灵动岛，在「设置 → 通用 → 快捷键」里可以修改或清空。
- **导入**：第一次启动时自动导入独立版 Focus 的时段、专注记录和偏好，Status 的设置和电量记录，以及 Dayline 的样式设置。导入后可以退出并删除这几个 App（Focus 如果打开了「防止被强行退出」，先在它的设置里关掉）。

## 改进

- 灵动岛支持鼠标滚轮：上下滚动翻页、收起时向下滚动展开，左右滚动切歌。
- 播放器的跳动音量条改成五根带柔光的细光条，颜色取自封面；暂停时封面稍稍退后。
- AirPods 按型号显示对应图标。
- 设置新增「专注」「状态」两页；时区选择支持中英文城市搜索；时段编辑器改用系统的玻璃侧栏。

## 权限说明

- 自动化（只在时段里暂停网站时需要）：读取浏览器当前标签页的网址，每个浏览器第一次会询问，不会记录或上传浏览记录。
- 登录项（可选）：「防止被强行退出」需要在「系统设置 → 通用 → 登录项」里允许。
- Perch 未经公证，**更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次**，蓝牙也会重新询问。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.4.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
