Perch 0.9.0：晾衣绳分成两段、两个文件夹，小鸟会飞来落在绳上；灵动岛下的细条有了萤火。

## 新功能

- **两段绳，两个文件夹**：右边那段放随手截的图，存在默认截图文件夹，点 ✕ 直接进废纸篓，方便统一清理；左边那段存进你选的文件夹（默认「图片/截图收藏」，可以换成你的「学习资料」），从绳上取下时文件还在。
- **切换挂到哪边**：两段绳内侧端头各有一个小标签，平时只是一个圆点和图标，绿点表示新截图挂在这一段；指针移上去展开显示文件夹名，点一下切换。Perch 菜单 › 晾衣绳和「设置 → 晾衣绳」里也能切。
- **换边**：把照片拖到另一段绳上，那段会亮起来，松手后照片飞过去，文件也跟着挪进那段的文件夹；右键照片 › 挪到… 也可以。
- **小鸟**：晾衣绳放下时，偶尔有麻雀、树麻雀、山雀、知更鸟、燕子、金翅雀飞来落一会儿。每次来几只、从哪飞来、落在哪、停着时做什么（回头看、转身小跳、啄绳子、理羽毛、翘尾巴、眨眼）都不一样；落下时绳子会微微一沉、弹一下。晾衣绳收起或指针靠近时，它们飞过菜单栏离开屏幕。可以在「设置 → 晾衣绳」里关掉，开了「减弱动态效果」时不会出现。
- **细条下的萤火**：灵动岛下的细条闲置时，专注期间有一点暖光在下面缓缓呼吸；今天还有任务时，一到三点萤绿光在下面飞舞、不时闪亮，每点代表一项没做完的事，飞近时玻璃会映出它们的光。可以在「设置 → 灵动岛」里关掉。

## 改进

- 一段绳挂满后，最早那张只从绳上落下，文件留在原来的文件夹里，不再被删除。
- 指针停在菜单栏放下晾衣绳的区域，从中间三分之一放宽到中间一半（灵动岛那段仍然留给灵动岛）。
- 新截图挂上后晾衣绳停留的时间可以设置（3、5、8、12 秒，默认 5 秒），指针离开后也多等一会儿再收起。
- 灵动岛下细条的感应范围缩小了一些，不会再碰到晾衣绳的标签。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.9.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
- Perch 未经公证，更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次。
