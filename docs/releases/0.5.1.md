Perch 0.5.1：整理与精简。

## 改进

- **设置重新组织**，七页变六页：
  - 通用：语言、时区、登录时启动与防止被强行退出、所有快捷键（任务、灵动岛、专注、晾衣绳）、更新。
  - 灵动岛：灵动岛本身，以及系统状态页、菜单栏读数、刷新间隔和提醒（原「状态」页并入这里）。
  - 待办：任务显示在哪里、胶囊、胶囊里的时间（跟随 Perch 的语言）、音效与彩带。
  - 专注：今日专注、专注画面、时段。
- **时段直接在「设置 → 专注」里编辑**：可以从预设新建，点一行就在设置里弹出编辑表单，不再有单独的时段窗口。
- **去掉单独的系统状态面板**：系统状态都在灵动岛的状态页里，点菜单栏读数直接打开它。
- **晾衣绳**回到菜单栏中间三分之一触发（灵动岛那一段除外）。

## 功耗

- 屏蔽网站用的浏览器检查只在有屏蔽网站的时段进行中才运行（之前一直每 0.8 秒唤醒一次）。
- 胶囊显示时间时不再每秒重绘，只在时间出现、整分钟和任务回来时更新。
- 晾衣绳收起时，检查指针的频率从每秒 30 次降到 8 次。
- 系统状态只采样用得到的数据：不再记录 24 小时电量、外设电量和功率曲线；电量、GPU、Wi-Fi、网络延迟和磁盘只在需要时读取。
- 常驻定时器允许系统合并唤醒。

## 权限说明

- Perch 未经公证，**更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次**。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.5.1.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
