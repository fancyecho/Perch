Perch 0.5.0：截图晾衣绳，以及更从容的系统状态页。

## 新功能

- **截图晾衣绳**（改编自 Alejandro Buján 的开源项目 [Tendedero](https://github.com/alejandrobujan/tendedero)，MIT 许可）：截下的图挂在屏幕顶部的绳子上。
  - 绳子分成左右两段，中间留给灵动岛和胶囊。
  - 点一下复制，双击用预览打开，按住标记，拖进 App 发一份，拖进文件夹保存，拖到废纸篓或点叉丢掉；指针在照片上按空格快速查看、按 ⌫ 丢掉，在绳上按 ⌘Z 挂回刚丢的。
  - 右键可以固定（钉在左边不被挤掉）或拿在手上；录屏挂上去带播放按钮，按住可以裁剪。
  - 指针顶到屏幕上沿（正中除外）或按 `⌃⌥T` 放下晾衣绳；新截图挂上时会自己放下来一会儿，全屏 App 上也一样（可在设置里关掉）。
  - 可选「接管截图」：截图即刻挂上，不再出现浮动缩略图，也不会堆到桌面；改的是「⌘⇧5 › 选项」里的设置，关掉或退出 Perch 时还原。还可以挂上复制的图片、同时监视别的文件夹。
  - 访达里右键图片 › 服务 › Hang on Perch，可以把任意图片挂上绳。
  - 设置在「设置 → 晾衣绳」，常用操作在 Perch 菜单的「晾衣绳」里。

## 改进

- **系统状态页重新排版**：页面稍宽稍高，分成四行——电量和设备（只显示图标和数字，名字在悬停提示里）、四个读数、所选读数的曲线、底部常驻的磁盘占比条。温度只显示读数，不再有曲线；磁盘读写曲线去掉了。
- 读数更新时圆环不再左右跳动；磁盘条改成银色，不再和内存压力偏高时的橙色撞色。
- 胶囊里时间和任务的切换改成先淡出、再升起，不再同时交叠、斜着飘。

## 修复

- Perch 和晾衣绳的全局快捷键互相区分，不会误触对方。

## 权限说明

- 第一次启用晾衣绳时，系统会询问能否访问「桌面」文件夹（用来发现新截图）。
- Perch 未经公证，**更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次**。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.5.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
