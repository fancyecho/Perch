Perch 0.3.0：刘海灵动岛。

## 新功能

- **刘海灵动岛**：刘海变成一块会变形的黑色岛屿，切换桌面、锁屏时始终贴在刘海上。
  - 音量、亮度变化时向两侧展开提示，进度条随程度变色（可改成单色、显示百分比、调停留时长），可直接拖动调节。授权「辅助功能」后由 Perch 接管音量和亮度键，系统自带的提示不再出现。
  - 正在播放：封面和跳动的音量条常驻刘海两侧，切歌时弹出歌名；悬停展开成播放器，可拖动进度、切歌、打开来源 App。支持 Apple Music、Spotify、浏览器等任意 App。
  - 蓝牙设备连接 / 断开（AirPods 显示耳机和充电盒电量）、音频输出切换、插拔电源、低电量、充满、低电量模式都会提示。
- **刘海下的待办胶囊**（默认）：玻璃胶囊挂在刘海正下方，和灵动岛同宽、一起移动；悬停放大并预览接下来的任务，点击或快捷键展开成完整的任务面板。也可以在设置里选「融入灵动岛」或原来的「独立浮动胶囊」。
- **到点提醒**：任务到时间时刘海弹出提醒，可直接「完成」或「稍后」。
- **手势**：在刘海上双指左右滑切歌、上下滑展开收起；在胶囊上右滑完成、左滑推迟到明天。刘海和胶囊都有右键菜单。
- **锁屏**：刘海显示锁头，解锁时弹开；锁屏期间只能控制播放，任务不会出现。
- **小惊喜**：插电、清空今天、电量不足时，一圈光沿灵动岛边缘走过。

## 改进

- 设置改为「通用 / 待办 / 灵动岛 / 帮助」四个分页。

## 权限说明

- 蓝牙：首次启动时询问，用于显示设备和电量。
- 辅助功能（可选）：用于接管音量和亮度键。Perch 未经公证，**更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次**。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.3.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```

需要 macOS 26 或更高版本。`Perch-0.3.0.zip.sig` 是更新校验用的签名文件，手动安装时无需下载。
