Perch 0.4.1：灵动岛的细节打磨。

## 改进

- **`⌥C` 改为展开 / 收起灵动岛**（0.4.0 里是开关整个灵动岛功能）。用快捷键打开后，鼠标不在岛上也不会自己收回，再按一次收起；可在「设置 → 通用 → 快捷键」里修改或清空。
- **状态页加上磁盘**：顶部一行右端显示磁盘剩余空间，点它在下面看已用占比条和读写曲线；用量超过 90% 变成橙色。
- **状态页的圆环更有信息量**：网速圆环左右两半分别是上传和下载，长度对比最近两分钟最快的一次；温度圆环从薄荷绿渐变到红，日常温度也能看出变化，温度计图标随温度变化。
- **音量 / 亮度条重新设计**（参照 Alcove）：音量条整条一起变色，平时绿色、偏大转琥珀、接近最大转红；亮度条是由灰到白的渐变，越亮露出的白色越多；两者都带同色光晕。
- **跳动的音量条**改成实心圆头细条，颜色取自封面并调柔和，暂停时缩成小圆点。
- **灵动环**（时段进行中胶囊外圈那道环）光效稍亮一些，悬停放大时和任务环同步，不再错位。
- **插电、清空任务等光效**改成一道沿灵动岛下缘扫过、尾巴渐隐的光，不再绕整个岛描边，避开顶部的尖角。
- **胶囊里的时间**：任务逾期时不再一直挡住时间，「和任务轮流」「整分钟前后」恢复正常；「常显时间」模式下，逾期或快到期的任务会和时间轮流出现。
- **输出设备图标**：有线 EarPods 不再显示成音箱；AirPods 4 / 3 代、Beats、HomePod、显示器等按名字对应图标。

## 权限说明

- Perch 未经公证，**更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次**，否则按音量、亮度键时系统自带的提示框会和灵动岛同时出现；蓝牙也会重新询问。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.4.1.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
