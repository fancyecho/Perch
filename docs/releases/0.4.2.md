Perch 0.4.2：修复闪退和启动卡顿。

## 修复

- **打开系统状态面板时闪退**：面板展开时窗口大小被反复调整，触发的布局次数超出系统上限导致退出。现在窗口大小由 Perch 自己决定，灵动岛和任务面板的窗口也一并修正。
- **启动卡顿、灵动岛和胶囊迟迟不出现**：打开「防止被强行退出」时，每次启动都会在主线程上等待后台保活进程接手，最多卡 4 秒。现在照常启动，保活进程起来后再接手，启动后约 1 秒灵动岛就会出现。
- 更新后第一次启动时，会重新登记后台保活进程。

## 已知问题

- Perch 未经公证、没有固定签名，系统在每次更新后都把它当作新 App：「防止被强行退出」的后台进程可能无法启动，辅助功能权限也需要重新授权（「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开），否则音量、亮度的系统提示框会和灵动岛同时出现。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.4.2.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
