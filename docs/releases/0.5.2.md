Perch 0.5.2：专注时段可以休息了。

## 改进

- **严格时段也能休息**：每天 3 次，每次 5、10、15 或 30 分钟，在拦截界面选好时长后按住按钮 3 秒。休息到点自动结束，被暂停的 App 会照常退出、网站标签页照常关掉。
- 严格时段的其他限制都不变：时段进行中不能停用、修改或删除，不能退出 Perch，被强行结束会自动重开，时区也不能改。
- **温和时段的休息规则同步**：同样每天 3 次、每次 5–30 分钟可选（之前固定 5 分钟）。
- 3 次是所有时段一起算的；上次选的时长下次会默认选中。
- 刘海旁的休息倒计时按实际时长显示进度。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.5.2.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
- Perch 未经公证，更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次。
