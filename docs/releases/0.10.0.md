Perch 0.10.0：把文件拖到刘海就能隔空投送；没在播放时，展开的灵动岛变成一排快捷按钮。系统状态功能已移除。

## 新功能

- **拖到刘海，隔空投送**：把文件、图片或链接拖向刘海，灵动岛会张开接住它，一圈圈蓝色波纹从摄像头处荡开。拖到岛上时波纹加快、图标散开浮起，触控板轻轻一震；松手后图标飞进摄像头，系统的隔空投送窗口从刘海里展开，选好设备就发出去，送达后岛下缘扫过一道蓝光。晾衣绳上的截图也能直接拖过来。可以在「设置 → 灵动岛 → 隔空投送」里关掉。
- **快捷按钮**：没在播放时展开灵动岛，原来的「没有正在播放的内容」换成一排按钮：隔空投送（选文件发送）、投送剪贴板（按钮会跟着你刚复制的东西变成「投送链接 / 图片 / 文件」）、专注、晾衣绳。指针移上去时按钮亮成各自的颜色。只有点下去才会读取剪贴板，展开灵动岛不会触发系统的剪贴板提示。
- **电量**：没在播放时，展开的灵动岛左上角显示 Mac 的电量。

## 移除

- **系统状态**：灵动岛的系统状态页、菜单栏读数，以及过热、内存、磁盘、进程占满 CPU 的刘海提醒都已移除，后台也不再定时采集这些数据。充电、低电量、蓝牙设备、音频输出的提示不受影响。
- 灵动岛现在只有一页：展开后双指上滑或向上滚动鼠标滚轮就收起。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.10.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
- Perch 未经公证，更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次。
