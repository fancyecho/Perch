Perch 0.2.0：更好看的「今天」，更有成就感的完成，以及随时改时间。

## 新功能

- **修改日期和时间**：已经添加的任务可以随时改。悬停在任务上点日历按钮，或点任务下方的日期、时间轴左侧的时间，或右键「修改日期和时间…」。可以用快捷日期、月历、时间开关和常用时刻，也能直接输入「后天下午3点」。修改即时生效，提醒同步更新。
- **今天时间轴**：有时间的任务按顺序串在一条线上，「现在」标记实时走动，已过去的一段逐渐着色，下一项显示倒计时；无时间的任务接在虚线的「随时」段。可在设置或 ⋯ 菜单中关闭。
- **完成的小奖励**：清脆的「嘀嗒」完成音，勾选时对勾描画、火花飞散、进度环弹跳；清空今天时响起上行琶音并撒下彩带。音效和彩带都可以在「设置 → 体验」中关闭或更换音色。

## 改进

- 悬停任务时不再出现「开始专注」按钮，改期按钮占固定位置，标题不会因此换行（专注仍可在右键菜单中开启）。
- 「即将」分组里不再重复显示日期。

## 安装与更新

- 已安装 0.1.0：Perch 会在 ⋯ 菜单和「设置 → 更新」中提示新版本，一键安装并重启。
- 首次安装：下载下方的 `Perch-0.2.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。应用未经 Apple 公证，首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```

需要 macOS 26 或更高版本。`Perch-0.2.0.zip.sig` 是更新校验用的签名文件，手动安装时无需下载。
