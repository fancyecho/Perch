Perch 0.8.1：刘海下的胶囊闲置时收成一道细条，鼠标停上去像水一样汇成胶囊。

## 新功能

- **闲置时收成细条**：没人看的时候，胶囊收成刘海下一道短短的玻璃细条，长度约是灵动岛的五分之一，随灵动岛一起变宽变窄。
- **像水一样汇聚**：鼠标移到细条上，它先微微一动；停一下，先横向拉成细长的水滴，再往下鼓成胶囊，文字随后从模糊里显出来。移开后按原路收回。
- **不挡点击**：细条周围的感应区只感应鼠标，点击照常落到下面的窗口，不会挡住浏览器标签页。
- 今天的任务全部完成时，细条会醒来放礼花，再收回去。

## 改进

- 「设置 → 任务」里新增「闲置时收成细条」开关（默认打开）；关掉后回到原来的胶囊，可以继续用「闲置时淡化」。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.8.1.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
- Perch 未经公证，更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次。
