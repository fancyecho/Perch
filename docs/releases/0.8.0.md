Perch 0.8.0：任务可以带子任务和备注了；面板里 ⌘Z 能撤销任何改动。

## 新功能

- **子任务和备注**：悬停任务时，改期按钮旁边会淡入一个清单按钮（也可以右键「添加子任务」「添加备注」），任务就在原地展开：一列小勾选圈的子任务，下面是一段备注。子任务里按回车接着加下一项，在空的一项里按删除键把它去掉。标题下一行轻轻标着「☑ 2/5」和备注图标，点它展开或收起。
- **展开时只显示写了的内容**：「添加子任务 / 添加备注」收在底部一行淡灰字里，指针移上去才出现。
- **时间轴上也能展开**：展开的内容挂在任务下面，连线照常穿过，拖动改时间、横扫都不受影响。
- **重复任务带着清单**：下一次会带着同样的子任务（全部未勾）和备注；跳过这一次时，子任务也会重新开始。
- **⌘Z 撤销、⇧⌘Z 重做**：改名、改颜色、勾子任务、拖动改时间……面板里的任何改动都能一步步撤回；提示条还在时，⌘Z 就等于点它的「撤销」。

## 改进

- 灵动岛的任务列表里，带子任务的任务后面多一个小小的「2/5」。

## 安装与更新

- 已安装旧版本：在 ⋯ 菜单或「设置 → 通用 → 更新」中一键安装并重启。
- 首次安装：下载下方的 `Perch-0.8.0.zip`，解压后把 `Perch.app` 拖进「应用程序」。首次打开请在「系统设置 → 隐私与安全性」中点「仍要打开」，或执行：
  ```
  xattr -dr com.apple.quarantine /Applications/Perch.app
  ```
- Perch 未经公证，更新后需要在「系统设置 → 隐私与安全性 → 辅助功能」里把 Perch 关掉再打开一次。
