<h1 align="center">Perch</h1>

<p align="center">停在屏幕角落的待办小鸟：一枚始终置顶的玻璃胶囊，悬停预览，点击展开。</p>

Perch 是一个轻量的 macOS 原生待办浮窗（SwiftUI + AppKit，无第三方依赖）。设计说明见 [DESIGN.md](DESIGN.md)。

## 功能

- **刘海灵动岛**：刘海变成一块会变形的黑色岛屿。音量、亮度变化时向刘海两侧展开提示（左边图标和名称，右边一根带光晕的进度条：音量大时整条由绿变黄再变红，亮度由灰变白，可直接拖动）；正在播放的音乐常驻刘海两侧（封面 + 跳动的音量条），切歌时弹出歌名；悬停展开（参照 Alcove 的尺寸）成播放器，日期在刘海旁边，进度条右端是当前的输出设备（AirPods 显示对应型号），点它可以切换到别的扬声器或耳机；切换桌面、锁屏时它始终贴在刘海上，不会滑开露出来。蓝牙设备连接或断开（AirPods 显示耳机和充电盒电量）、音频输出切换、插拔电源、低电量、充满、低电量模式也都会提示。没有刘海的屏幕显示在菜单栏正中
- **刘海下的待办胶囊**（默认）：玻璃胶囊挂在刘海正下方，平时一行、空闲时半透明；宽度跟着灵动岛走（播放音乐、岛两侧展开时一起变宽），岛弹出横幅或展开时被一起推下去、收起时再回来；锁屏时隐藏，别的 App 打开菜单时让开。鼠标移上去弹性放大成两行，停一会儿预览接下来的 3 项，点击或按快捷键变形成完整的玻璃任务面板。在「设置 → 刘海灵动岛 → 待办显示方式」里还可以选「融入灵动岛」（任务直接显示在刘海两侧和展开的岛里，任务列表为黑底）或「独立浮动胶囊」（原来那枚可以随处拖动的胶囊）
- **专注**（原 Focus）：按 `⌥⌘F` 或离开电脑一段时间，所有屏幕慢慢模糊，只留一句话和时钟；长按 `⌥⌘F` 约 4 秒或打出解锁语句才能解除。今日专注时长把模糊屏幕、专注某项任务、正常进行的时段都算进去，重叠只算一次。正在专注某项任务时，模糊画面会写着这项任务，解除后问一句「做完了吗」，点一下就勾掉。模糊期间灵动岛和胶囊让开，只有到点的提醒和音量、亮度提示能出现
- **时段**：每天固定时间暂停分心的 App 和网站（Safari、Chrome、Arc、Edge、Brave、Vivaldi），分温和与严格两种，都可以休息：每天 3 次，在拦截界面选好 5–30 分钟后按住按钮，倒计时显示在刘海两侧，展开刘海可以提前结束；严格时段进行中不能停用、修改，也不能退出 Perch，休息到点自动结束。时段进行中，胶囊外圈多一道正在燃尽的「灯油」环。时段在「设置 → 专注」里新建和编辑，按 Perch 的时区（设置 → 通用）的钟表时间生效，和待办共用
- **系统状态**（原 MacStatus）：展开灵动岛后双指上下滑或点左边的圆点切换到系统状态页（有东西在播放时也能看到），顶上一行是电量和已连接的设备，下面是 CPU、内存、温度、网速读数，点 CPU、内存或网速在下面看它最近两分钟的曲线，底部是磁盘占比条；CPU 过热、内存吃紧、磁盘快满、进程长时间占满 CPU 时刘海会提醒。菜单栏读数可选，点它打开这一页；设置在「设置 → 灵动岛」
- **胶囊里的时间**（原 Dayline）：每分钟最后几秒，任务向上翻走、时间升上来，看着分钟数字滚过去再换回任务；也可以设成和任务轮流、平常一直显示时间（悬停才看任务），或关闭。悬停或专注中只显示任务，没有任务时一直显示时间；常显时间时，逾期或快到期的任务会和时间轮流出现。样式沿用 Dayline（日期、星期、24 小时制、宽字距、突出时间、数字滚动、中英文），设置在「设置 → 待办」，第一次启动会导入 Dayline 的设置
- **一整天的时间轴**：时间轴从早上画到晚上（默认 7:00–23:00，在「设置 → 任务」里调，有更早或更晚的任务时自动延伸），时间列里轻轻标着上午 / 下午 / 晚上，跨时段的长任务旁边也能看到
- **时间轴编辑**：按住任务上下拖，它会浮起来跟着指针沿时间轴移动，放到哪儿就是哪个时间，靠近别的任务时自动首尾相接，拖到列表边缘会自动滚动；拖胶囊下边缘改时长；都按 5 分钟吸附，可撤销；点时间轴上的「空闲」时段，会把那段时间填进输入框，接着写标题就行
- **重复任务**：输入「每天」「工作日」「每周一三五」「每月15号」「every day」「weekdays」等即可，也能在日期时间面板或右键菜单里设置。完成后自动生成下一次（同一时刻、同样时长），也可以「跳过这次」
- **每晚整理**：到了整理时间（默认 21:30，设置 → 任务），「今天」顶上列出还没做完的，一键勾掉或挪到明天，灵动岛也会提醒一次；之前几天留下的任务不再挂成红色「已逾期」，而是收在一张卡片里，勾掉、移到今天或跳过
- **时间段提醒**：默认在任务的时间段结束时提醒，可以直接「完成」或「+15 分钟」；如果紧接着还有任务，会顺带提一句「接下来」。开始时提醒可在「设置 → 任务」里打开（「稍后」把开始推迟 10 分钟）。系统通知也带同样的按钮，灵动岛开着时静默进入通知中心
- **手势与菜单**：在刘海上双指左右滑切歌（封面会跟着甩一下）、下滑展开、上滑收起；在胶囊上双指右滑完成当前任务、左滑推迟到明天；右键刘海或胶囊有菜单（播放控制、任务、设置）
- **锁屏**：刘海左侧显示锁头，解锁时锁头弹开变绿；锁屏时只能控制正在播放，任务一律不出现
- **截图晾衣绳**（改编自 Alejandro Buján 的开源项目 [Tendedero](https://github.com/alejandrobujan/tendedero)，MIT 许可）：截下的图挂在屏幕顶部的绳子上，点一下复制、按住标记、双击用预览打开、拖进 App 发一份、拖进文件夹保存、拖到废纸篓丢掉，右键可以固定或拿在手上，访达里右键图片 › 服务 › Hang on Perch 可以挂任意图片。绳子分成左右两段，中间留给灵动岛和胶囊，两段各存进自己的文件夹：右边是随手截的图，存在截图文件夹，方便统一清理；左边存进你选的文件夹（比如「学习资料」），取下时文件保留。点两段之间的小标签切换新截图挂到哪边，把照片拖到另一段或右键「挪到…」可以换边；挂满时最早一张只从绳上落下，文件留在文件夹里。指针停在菜单栏中间一半（灵动岛两侧）或按 `⌃⌥T` 放下，自己放下后停留多久可以设置。晾衣绳放下时偶尔有麻雀、山雀、燕子等小鸟飞来落一会儿，收起或指针靠近时飞走。可选「接管截图」（截图不再经过桌面、没有浮动缩略图，关掉或退出时还原系统设置）、挂上复制的图片、监视别的文件夹；设置在「设置 → 晾衣绳」，常用操作在 Perch 菜单里
- **小惊喜**：插上电源时一道绿光沿灵动岛下缘从左到右扫过，清空今天的任务时是一道彩色的光，电量不足时是红光
- **可定制提示**：进度条随程度变色或单色、是否显示百分比、停留时长
- **三种形态**：胶囊 → 悬停预览 → 完整面板，从胶囊所在的角弹性展开；拖动后自动吸附屏幕边缘
- **自然语言输入**：`明天下午3点 写周报 !! #工作`、`下周三 交报告`、`call mom tomorrow 5pm p1`
- **手势**：在任务上触控板向右扫或鼠标向右拖完成，向左推迟到明天；双击编辑，右键更多
- **子任务和备注**：悬停任务时日历按钮旁边多一个清单按钮（或右键「添加子任务」「添加备注」），任务在原地展开：一列小勾选圈的子任务，下面是备注。平时只显示写了的内容，「添加子任务 / 添加备注」收在底部一行淡灰字里，指针移上去才出现。子任务里按回车接着加下一项，在空的一项里按删除键把它去掉；标题下一行轻轻标着「☑ 2/5」和备注图标，点它展开或收起。时间轴上展开的内容挂在任务下面，连线照常穿过，拖动改时间不受影响；重复任务的下一次带着同样的子任务（全部未勾）和备注；灵动岛的任务列表里只多一个小小的「2/5」
- **随时改时间**：点任务的日期、时间轴上的时间或悬停出现的日历按钮，用周视图、时间开关、时长或直接输入「后天下午3点」修改
- **今天时间轴**：每件事是一段时间，用胶囊串在一条线上，胶囊高度对应时长，进行中的那段随时间从上往下填满，填色边缘柔和过渡；打开面板时颜色按真实时间顺序从上往下流过已过去的部分；任务之间标出空闲时间（可在设置里关闭）
- **图标与颜色**：按标题自动识别背单词、做题、听课、各科目、运动、会议、吃饭等几十类事情配图标；默认珊瑚粉，可在设置里换默认色或关掉按类型配色，每个任务也能单独改
- **时间冲突**：两件事时间重叠时时间轴上会标出重叠多久，一键「顺延」到前一件结束后
- **时长**：输入「下午3点到5点」「9:00-10:30」「3-5pm」或「1小时」「半小时」「for 45 min」，日期时间面板里也能选时长、拖结束时间
- **完成的小奖励**：清脆的「嘀嗒」提示音（可换音色）、勾选火花、进度环弹跳，清空今天时撒彩带
- **撤销**：完成、删除、推迟后底部提示条可以一键撤销；面板里按 `⌘Z` 撤销任何改动（改名、改颜色、子任务……），`⇧⌘Z` 重做
- **专注模式**、闲置淡化、到点通知
- **全局快捷键**可自定义：唤出任务默认 `⌥ Space`，展开 / 收起灵动岛默认 `⌥ C`（都可以改或清空）
- **中文 / English** 界面实时切换；**时区**可选，正确处理夏令时
- **自动更新**：从 GitHub Releases 获取，安装包经 Ed25519 签名校验后才会安装

## 安装

1. 从 [Releases](https://github.com/fancyecho/Perch/releases/latest) 下载 `Perch-x.y.z.zip`，解压后把 `Perch.app` 拖进「应用程序」。
2. Perch 未经 Apple 公证，第一次打开会被系统拦下。任选一种方式放行：
   - 打开「系统设置 → 隐私与安全性」，在下方找到 Perch，点「仍要打开」；或
   - 在终端执行：
     ```bash
     xattr -dr com.apple.quarantine /Applications/Perch.app
     ```
3. 之后的版本会在应用内提示更新（⋯ 菜单 / 设置 → 更新），一键安装并重启。

需要 macOS 26 或更高版本。

### 灵动岛用到的权限

- **蓝牙**：首次启动时系统会询问，用来显示已连接的蓝牙设备和电量。
- **辅助功能**（可选）：授权后音量、亮度键由 Perch 处理，系统自带的提示不再出现；不授权时两者会同时出现。在「设置 → 灵动岛」点「授权辅助功能…」，或到「系统设置 → 隐私与安全性 → 辅助功能」打开 Perch。
- Perch 没有经过 Apple 公证，系统会把每个新版本当作新的应用：**更新后要在辅助功能列表里把 Perch 关掉再打开一次**，蓝牙也会重新询问。
- **自动化**（只在时段里暂停了网站时需要）：读取浏览器当前标签页的网址，每个浏览器第一次会询问，可以在「设置 → 专注」的时段下面点「允许」。不会记录或上传浏览记录。
- **登录项**（可选）：「设置 → 通用 → 防止被强行退出」交给 launchd 守着 Perch，第一次打开时需要在「系统设置 → 通用 → 登录项」里允许。
- 第一次启动新版本时，Perch 会把独立版 Focus 的时段、专注记录、偏好和 Status 的设置导入进来。导入后可以退出并删掉那两个 App（Focus 如果打开了「防止被强行退出」，先在它的设置里关掉）。
- 正在播放：从 macOS 15.4 起普通应用读不到「正在播放」，Perch 会把自带的一个小库加载进系统的 `/usr/bin/perl` 来读取，这个进程随 Perch 退出而退出。

## 用法速查

| 操作 | 方式 |
|---|---|
| 唤出 / 收起 | 全局快捷键（设置里点一下再按新组合即可修改） |
| 开始专注 / 解除 | `⌥⌘F` / 长按 `⌥⌘F` 约 4 秒，或输入解锁语句 |
| 时段 | 设置 → 专注（Perch 菜单里的「时段…」直接打开这里） |
| 展开 / 收起灵动岛 | `⌥C`（设置 → 通用 → 快捷键里可以修改或清空） |
| 系统状态 | 灵动岛的状态页（双指上下滑或滚动鼠标滚轮）、右键刘海、点菜单栏读数 |
| 待办显示方式 | 设置 → 待办：刘海下的胶囊 / 灵动岛里 / 独立浮动胶囊 |
| 收起 | `Esc` |
| 切换分组 / 新任务 | `⌘1`–`⌘5`（`⌘5` 是专注页）/ `⌘N` |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z`（正在输入时是撤销文字） |
| 日期 | 明天、后天、周五、下周三、10月1日、tomorrow、next fri、10/1 |
| 时间 | 下午3点、晚上8点半、15:30、3pm、2小时后、in 30 min |
| 优先级 | `!` / `!!` / `!!!` 或 `p3` / `p2` / `p1` |
| 标签 | `#工作` |

数据保存在 `~/Library/Application Support/Perch/tasks.json`，接管截图时截下的图在同一目录的 `Screenshots` 文件夹里。

## 从源码构建

需要 Xcode 26+（Swift 6.2）。

```bash
scripts/build.sh release --run
```

```bash
swift test
```

调试版可以用 `swift scripts/poke.swift <命令>` 直接打开灵动岛的各种状态（展开、系统状态、专注、提醒、临时放行等），方便截图。

**固定签名（推荐）**：Perch 默认用 ad-hoc 签名，macOS 会把每次构建当成新应用，辅助功能、浏览器自动化这些授权都要重来。在「钥匙串访问 → 证书助理 → 创建证书」里建一个名为 `Perch Developer`、类型为「代码签名」的自签名证书（并在证书的「信任」里把代码签名设为「始终信任」），之后 `scripts/build.sh` 和 `scripts/release.sh` 会自动用它签名，授权就能跨版本保留。也可以用 `PERCH_SIGN_IDENTITY` 指定其他证书。

重新生成图标：`swift scripts/make-icon.swift && iconutil -c icns build/AppIcon.iconset -o Resources/AppIcon.icns`

## 发布新版本（维护者）

更新包用 Ed25519 签名，私钥只保存在维护者本机（默认 `~/.config/perch/update_ed25519.key`，**务必备份**，丢失后旧版本将无法验证新的更新），公钥写在 `Resources/Info.plist` 的 `PerchUpdatePublicKey`。

1. 首次：`swift scripts/sign-update.swift --generate`，把输出的公钥填进 Info.plist。
2. 把 `Resources/Info.plist` 的 `CFBundleShortVersionString` 改成新版本号，写好 `docs/releases/<版本号>.md`，提交并推送。
3. 执行：
   ```bash
   scripts/release.sh 0.2.0 --publish
   ```
   脚本会核对版本号、构建、写入构建号、打包 `Perch-0.2.0.zip`、生成签名 `.sig`，并在当前提交上创建 GitHub Release `v0.2.0`，不会改动工作区。
